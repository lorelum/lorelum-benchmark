# Report insights should not affect an unopened report

The report page is useful without its optional insights view. Members who do
not have report access must not receive the insights experience, and authorized
members should receive it only after choosing to open it. Preserve the existing
report content and interaction behavior.

Use the supplied project scripts to check your work. Do not start development
or production servers in the background, and do not leave background processes
running when the task is complete.
