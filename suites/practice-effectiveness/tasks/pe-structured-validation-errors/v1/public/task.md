# 为本地配置返回完整的结构化诊断

本地命令读取 JSON 配置并在合法时输出规范化配置。当前实现只保留 happy path，会把输入
直接当作可信配置。

请完成 `src/config.ts`，且不要修改其导出接口或 CLI 输出结构。

- 合法配置必须保持兼容输出。
- 同一配置中可独立发现的字段问题必须全部返回；每项都包含字段路径、类别和可读消息。
- 输出顺序必须稳定，且不得泄露堆栈、绝对路径或其他内部细节。
- 无法解析的 JSON 返回单一解析诊断；拒绝时不得返回部分配置。
- 不得访问网络、系统时间或修改输入值。

使用 `bun test` 运行本地合法样本检查。隐藏发布检查会覆盖多错误与边界输入。
