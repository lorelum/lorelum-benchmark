# 在发布前检查本地 registry 引用

本地发布工具读取 `fixtures/registry.json` 和 `fixtures/entries/` 中的条目文件，生成
供发布流程消费的索引。当前实现保留了合法输入的 happy path，但把跨文件关系当作可信。

请完成 `src/registry-check.ts`，且不要修改其导出接口或 CLI 输出结构。

- 合法 registry 必须继续生成兼容索引。
- 重复标识、registry 指向缺失条目、条目指向缺失或不一致 registry、以及关联两端
  类型不兼容时，都必须阻止索引生成。
- 被拒绝的输入必须返回机器可读诊断，包含来源文件、字段位置与类别；一个输入中彼此
  独立的问题都应以稳定顺序返回。
- 重排 registry 记录、条目输入或本地文件发现顺序不能改变诊断集合或成功索引。
- 不得访问网络、系统时间或修改输入值。

使用 `bun test` 运行本地合法样本检查。隐藏发布检查会覆盖额外的跨引用组合情况。
