# 为本地条目查询实现确定性边界

本地 `query` 命令从 `fixtures/items.json` 读取条目，并按 domain、status、标签和页码
返回结果。当前实现只保留了最简单的 happy path。

请完成 `src/query.ts`，且不要修改其导出接口或 CLI 输出结构。

- 合法查询必须返回兼容的 `items`、`page`、`pageSize` 和 `total` 响应；每页固定两条。
- 支持的过滤条件必须共同限制结果；重复标签不能改变语义。
- 未知 domain 或 status、无效页码和超出范围的页码必须返回清楚且一致的边界结果，
  不得混入不匹配条目。
- 重排底层条目不能改变规范化响应；结果应按 `id` 排序后再分页。
- 不得访问网络、系统时间或修改输入值。

使用 `bun test` 运行本地合法样本检查。隐藏发布检查会覆盖组合过滤与边界情况。
