# 发布说明应可执行

## 应当这样做

说明读者、变更范围、回滚负责人和记录归档位置；把待办写成发布后可以执行的检查项，并保持说明与当前发布范围一致。

## 避免

- 不要把历史背景当成操作步骤。
- 不要省略回滚负责人。
- 不要在说明中修改服务配置、端口暴露或部署命令。

## 完成前检查

检查说明是否包含读者、范围、回滚和归档四项信息。
