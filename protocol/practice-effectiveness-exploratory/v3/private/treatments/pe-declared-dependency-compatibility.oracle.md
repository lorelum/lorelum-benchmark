# 兼容保留暂未支持的声明

## 应当这样做

保留原始声明，返回明确的非阻断兼容性反馈；让调用方知道该字段已被识别但暂不生效，而不是尝试猜测或补全未定义的行为。

## 避免

- 不要静默忽略或删除该声明。
- 不要把它升级为阻断错误。
- 不要启动依赖解析器或实现当前版本未承诺的语义。

## 完成前检查

检查声明仍被保留、反馈可见，且结果保持可继续执行。
