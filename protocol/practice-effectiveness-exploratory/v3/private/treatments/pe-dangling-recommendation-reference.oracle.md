# 发布前决策目标必须可解析

## 应当这样做

在发布前验证每个决策目标都能解析为本地声明的条目。任何目标缺失都应阻断发布，并返回足以修复配置的反馈。

## 避免

- 不要让一个有效目标掩盖另一个悬空目标。
- 不要把不可解析目标保留为可发布状态。
- 不要推断不存在的条目。

## 完成前检查

检查完整配置可以发布，任一悬空目标都会被明确拒绝。
