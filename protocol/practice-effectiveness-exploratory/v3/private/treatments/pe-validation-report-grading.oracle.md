# 校验结果区分阻断与提示

## 应当这样做

将阻断性问题与非阻断性反馈分开保留；总体是否通过只由阻断性问题决定。调用方应能获得全部反馈，而不是只得到一个布尔值。

## 避免

- 不要因为存在警告或提示就阻断操作。
- 不要丢弃非阻断反馈。
- 不要以未分类的文本代替结构化结果。

## 完成前检查

检查错误会阻断，而警告和提示仍然可见且不会使结果失效。
