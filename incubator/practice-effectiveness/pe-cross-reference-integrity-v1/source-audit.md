# Source Audit — Registry Publication Kernel

## Status

`blocked`: the fixture is a contract-derived draft, not evidence of an existing
registry or publication workflow.

## Required evidence before candidate admission

- A real repository change, PR, incident, or review that identifies the registry,
  referenced entry types, and the publication consumer affected by invalid links.
- A team-confirmed, versioned Practice defining the applicable relationship boundary
  and explicit exclusions.
- Evidence for the real product's rejection behavior and diagnostic consumer. The
  fixture must not promote a generic graph rule into a product contract.
- A source-derived baseline failure hypothesis that can be tested without exposing the
  relationship rules in the public prompt.

## Runtime and privacy limits

The draft uses only local fixtures and excludes network access, clocks, external
registries, and production content. Promotion requires an equally deterministic local
representation of the approved source.
