# Practice 草案

此目录中的内容仅用于审核候选 Practice 与负对照设计，状态为
`draft-awaiting-review`。它们不是正式 Lorelum Practice，尚无冻结 revision、内容
hash、treatment 或 retrieval trace，不能用于 benchmark 运行或效果结论。

每个候选实验组包含一份相关 Practice 和一份长度、标题层级、示例数量及工具权限
相当但语义无关的负对照。审核通过后，才可将两者迁入未来的版本化 Practice 库，固定
内容 hash，并创建 `oracle-practice` 与 `irrelevant-practice` treatment。
