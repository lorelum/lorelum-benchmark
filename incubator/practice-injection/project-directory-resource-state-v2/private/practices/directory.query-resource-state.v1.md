# 前端查询资源状态约定

本仓库前端在读取远程列表的页面，按以下约定处理加载与状态：

1. 组件只负责搜索输入、触发查询和按状态呈现；远程读取委托给组件外的查询边界，不在组件里直接调用请求封装。
2. 边界模块负责发起请求并把传输 DTO 转换成界面可用的数据，不让原始 response 对象流进组件状态。
3. 在边界把成功、空结果和可恢复失败翻译成显式资源状态（如 ready/empty/failed）；组件只根据该状态显示反馈，不解释状态码。

反例：组件里直接调用 HTTP adapter、读取 status 或消费 response body、在组件里翻译 404/503 等传输细节。
