# 供应商接入与计费执行约定

本仓库模型网关按以下约定接入供应商并执行计费：

1. 定义统一模型客户端契约，请求、回复文本与 token 用量归一成同一形态；接口层只依赖契约，不感知具体供应商。
2. 每个供应商做独立适配器，只负责线协议翻译并输出规范化 usage 与类型化错误；OpenAI 兼容类复用同一适配器，伪兼容供应商必须按线协议单独实现。
3. fallback、重试、租户预算、幂等与计量统一集中在边界政策；重试和降级只是传输细节，一个逻辑请求只产生一条账本记录。
4. 供应商由配置/注册表驱动，接口层不按供应商名分支；费用换算、预算预占/结算与用量/耗时观测集中在边界账本统一做。

反例：接口按供应商名分支、伪兼容供应商套用 OpenAI 适配器、每家各写一套预算/计费路径、重试或降级双计费、流式失败漏账、原始 usage 字段或上游错误外泄。
