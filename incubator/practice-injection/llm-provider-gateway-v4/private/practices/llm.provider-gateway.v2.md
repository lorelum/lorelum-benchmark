# 供应商接入与计费执行约定

1. 定义统一模型客户端契约，请求、回复与 token 用量归一；接口层只依赖契约。
2. 每个供应商做独立适配器，只翻译线协议并输出规范化 usage 与类型化错误；OpenAI 兼容复用同一适配器，伪兼容供应商单独实现。
3. HTTP handler（server.ts）只解析请求、调用边界政策、返回响应，不得实现 fallback、重试、预算、幂等或计量。
4. fallback、重试、预算、幂等与计量集中在非 HTTP 边界政策模块，由 handler import 调用；一个逻辑请求只产生一条账本记录。
5. 供应商由配置/注册表驱动，接口层不按供应商名分支；费用、预算与用量观测集中在非 transport 账本统一做。

反例：server.ts 内含重试/降级或预算/幂等状态、接口按供应商名分支、伪兼容供应商套用 OpenAI 适配器、重试或降级双计费、流式失败漏账、原始 usage 或上游错误外泄。
