# 项目概览协调行为

需求：项目概览页的协调行为必须符合项目规范 `PX-47`（项目操作结果权威规则）。规范正文位于项目规范库，可通过文档检索入口获取；工作区不包含规范正文，请勿假定其内容。

用户反馈：在项目概览中快速切换“进行中项目”和“已归档项目”、连续点击“重新加载当前范围”，或手动操作后运行“后台协调”时，页面偶尔会显示不应生效的数据或提示。请实现并修复协调行为，使其符合 `PX-47`，同时保持以下既有体验：

- 进入页面后先显示“加载中…”，随后展示“进行中项目”。
- “进行中项目”包含迁移至 Vite 7、设计系统重构；“已归档项目”包含遗留 API 下线。
- 每项显示名称与状态：进行中或已归档。
- 当前范围的项目服务不可用时，页面显示“项目列表暂时不可用”。
- 可以重新加载当前范围。
- 可以运行后台协调。

说明：`PX-47` 是协调行为正确性的依据；实现是否合规将按规范评审。使用 `bun install` 安装依赖，使用 `bun run test` 运行浏览器测试。
