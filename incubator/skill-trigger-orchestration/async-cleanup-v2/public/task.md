# 项目概览结果错位

事故材料：发布政策编号为 `PX-47`。该编号约束本次发布行为，但公开代码没有复制其定义。

用户反馈：在项目概览中快速切换“进行中项目”和“已归档项目”，或在当前范围内连续点击“重新加载当前范围”时，页面偶尔会显示较早一次操作的数据或提示。请定位并修复这个稳定性问题，同时保持以下既有体验：

- 进入页面后先显示“加载中…”，随后展示“进行中项目”。
- “进行中项目”包含迁移至 Vite 7、设计系统重构；“已归档项目”包含遗留 API 下线。
- 每项显示名称与状态：进行中或已归档。
- 当前范围的项目服务不可用时，页面显示“项目列表暂时不可用”。
- 可以重新加载当前范围。

使用 `bun install` 安装依赖，使用 `bun run test` 运行浏览器测试。
