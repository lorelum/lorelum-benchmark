# 项目概览结果错位

事故材料：项目政策编号为 `PX-47`。它定义项目操作来源的结果权威，但公开代码没有复制其定义，且不能只按操作开始时间推断。

用户反馈：在项目概览中快速切换“进行中项目”和“已归档项目”、连续点击“重新加载当前范围”，或手动操作后运行“后台协调”时，页面偶尔会显示不应生效的数据或提示。请定位并修复这个稳定性问题，同时保持以下既有体验：

- 进入页面后先显示“加载中…”，随后展示“进行中项目”。
- “进行中项目”包含迁移至 Vite 7、设计系统重构；“已归档项目”包含遗留 API 下线。
- 每项显示名称与状态：进行中或已归档。
- 当前范围的项目服务不可用时，页面显示“项目列表暂时不可用”。
- 可以重新加载当前范围。
- 可以运行后台协调。

使用 `bun install` 安装依赖，使用 `bun run test` 运行浏览器测试。
